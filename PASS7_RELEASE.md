# AetherOS / AetherCore — Pass 7 Release Manifest

Pass 7 extends the universal capability architecture while keeping the DSi build deterministic, portable, and safe.

## Public Pass 7 scope

- Nintendo DSi / NDS runtime remains the primary verified local target.
- Capability-gated adapters for Nintendo, Sony, Xbox, Apple, Nokia/legacy mobile, desktop/server, and emulator frontends.
- Offline-first operation with local caches and deterministic safe-mode fallback.
- Outage-aware routing: local services continue when external gateways are unavailable.
- Web gateway architecture supports ordinary public-web HTTPS services and user-authorized endpoints.
- OEQL-style URI adapters can map to approved gateways without granting arbitrary network execution.
- Passive RF telemetry, receive-side lab instrumentation, spectrum visualization, and synthetic frequency-manipulation simulation.
- Defensive network monitoring and authorized test harnesses.
- Deterministic health checks and bounded self-repair for AetherOS runtime components.
- Public build artifacts are generated by CI; no placeholder NDS is intended for release.

## Security boundary

Pass 7 does **not** implement real-world radio jamming, covert interception, unauthorized packet interception, credential theft, or arbitrary access to dark-web services. Those capabilities can be represented by sandboxed simulations and defensive test fixtures only.

“Always online” is not guaranteed by a DSi or by software. Pass 7 instead uses an offline-first/fallback architecture so core functions remain usable during network or gateway outages.

## Cross-platform reality

A Nintendo DSi .nds executable cannot directly replace or execute every operating system ever made. Pass 7 therefore exposes explicit adapter contracts for capable hosts, native applications, emulators, and gateways. Platform-specific code must be supplied and executed on hardware that supports it.

Undocumented, secret, or banned operating systems are not claimed as known, obtained, or accessible.

## Build

The canonical artifact is produced by GitHub Actions from `main`:

- `AetherOS-Pass7.nds`
- `AetherCore1-Pass7-DSi-Public.zip`

The CI pipeline verifies the NDS payload/header and performs deterministic source sanity checks before publishing.
